# 💜 Pour Elé — 7 & 8 novembre 2026

Site-surprise statique (HTML/CSS/JS, aucune dépendance) pour un week-end d'anniversaire à Paris.

## Déploiement GitHub Pages

1. `Settings` → `Pages` → **Build and deployment** : Source = *Deploy from a branch*
2. Branch = `main`, dossier = `/ (root)` → **Save**
3. Le site est en ligne sous ~1 min à l'adresse `https://<user>.github.io/<repo>/`

## Personnalisation

- Les mots doux à rédiger sont marqués dans `index.html` par des commentaires `✏️ THÉO` (intro, cartes, mot de fin).
- Décompte : cible modifiable dans `script.js` (`TARGET`).
- Images : dossier `assets/`.

## Carton physique

`card.html` = carton A6 paysage prêt à imprimer (PDF) avec QR code vers le site (`assets/qr.png`).
